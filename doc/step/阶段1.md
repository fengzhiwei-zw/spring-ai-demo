### 阶段 1：环境搭建 & Hello World

#### 第一步：确认 JDK 版本

Spring AI 2.0.0 GA（2026年6月12日发布）**强制要求 Java 21+**，这是硬性底线。

打开终端执行：

```bash
java -version
```

**预期输出**（版本号 >= 21 即可）：
```
openjdk version "21.0.4" 2024-07-16
```

如果版本不够或没有安装，推荐通过 [Adoptium](https://adoptium.net/) 下载 JDK 21 LTS。Windows 用户安装后记得配置 `JAVA_HOME` 环境变量指向安装目录。

#### 第二步：选择 AI 模型方案

你有三种选择，我推荐**方案 A**作为学习起步：

| 方案 | 优点 | 缺点 | 适合 |
|------|------|------|------|
| **A. Ollama（本地）** | 免费、离线、零配置 | 模型能力弱于云端 | 学习阶段首选 |
| **B. DeepSeek API** | 性价比高、中文强 | 需要注册、微量费用 | 日常开发 |
| **C. OpenAI API** | 功能最全、效果最好 | 费用较高、需科学上网 | 生产环境 |

---

#### 方案 A：Ollama 本地部署（推荐入门）

**1. 安装 Ollama**

- 访问 [ollama.com](https://ollama.com) 下载安装包
- Windows 选 `.exe`，macOS 选 `.dmg`，Linux 用命令行：
  ```bash
  curl -fsSL https://ollama.com/install.sh | sh
  ```

**2. 拉取模型**

安装完成后，终端执行：
```bash
ollama pull qwen2.5:7b
```

这会下载一个约 4.7GB 的模型文件。如果网络慢，也可以选择更小的模型：
```bash
ollama pull qwen2.5:3b   # 约 1.9GB，适合内存较小的机器
```

**3. 验证 Ollama 是否正常运行**

```bash
ollama run qwen2.5:7b "你好，请用一句话介绍自己"
```

如果看到模型回复，说明 Ollama 已就绪。Ollama 默认在 `http://localhost:11434` 提供 HTTP 服务。

---

#### 方案 B：DeepSeek API（备选）

1. 访问 [platform.deepseek.com](https://platform.deepseek.com) 注册账号
2. 进入「API Keys」→「创建新 Key」，复制 `sk-` 开头的密钥
3. 设置为环境变量（**切勿硬编码到代码中**）：
   ```bash
   # Windows PowerShell
   $env:DEEPSEEK_API_KEY="sk-你的密钥"
   
   # macOS / Linux
   export DEEPSEEK_API_KEY="sk-你的密钥"
   ```

#### 第三步：创建 Spring Boot 项目

**方式一：通过 Spring Initializr 创建（推荐）**

1. 打开浏览器访问 [start.spring.io](https://start.spring.io)
2. 按以下配置选择：

| 配置项 | 选择 |
|--------|------|
| Project | Maven |
| Language | Java |
| Spring Boot | **4.0.0**（或 4.1.0） |
| Group | com.example |
| Artifact | spring-ai-demo |
| Packaging | Jar |
| Java | **21** |

3. 在 **Dependencies** 中添加：
    - `Spring Web`
    - `Spring AI` → 选择对应模型的 Starter（如 Ollama 或 OpenAI）

4. 点击 **Generate** 下载 zip 包，解压后用 IDE 打开

**方式二：手动创建 pom.xml**

如果 Initializr 上没有找到 Spring AI 选项，可以手动创建项目后修改 `pom.xml`。以下是完整的依赖配置：

```xml

         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 
         https://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>

    <parent>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-parent</artifactId>
        <version>4.0.0</version>
        <relativePath/>
    </parent>

    <groupId>com.example</groupId>
    <artifactId>spring-ai-demo</artifactId>
    <version>0.0.1-SNAPSHOT</version>
    <name>spring-ai-demo</name>

    <properties>
        <java.version>21</java.version>
        <spring-ai.version>2.0.0</spring-ai.version>
    </properties>

    <!-- Spring AI BOM 统一管理版本 -->
    <dependencyManagement>
        <dependencies>
            <dependency>
                <groupId>org.springframework.ai</groupId>
                <artifactId>spring-ai-bom</artifactId>
                <version>${spring-ai.version}</version>
                <type>pom</type>
                <scope>import</scope>
            </dependency>
        </dependencies>
    </dependencyManagement>

    <dependencies>
        <!-- Spring Boot Web -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-web</artifactId>
        </dependency>

        <!-- Spring AI 核心 Starter -->
        <dependency>
            <groupId>org.springframework.ai</groupId>
            <artifactId>spring-ai-starter</artifactId>
        </dependency>

        <!-- 
            模型适配器（根据你选的模型方案，三选一）：
            
            方案A Ollama：
            <dependency>
                <groupId>org.springframework.ai</groupId>
                <artifactId>spring-ai-ollama-spring-boot-starter</artifactId>
            </dependency>
            
            方案B/C DeepSeek 或 OpenAI（兼容OpenAI协议）：
            <dependency>
                <groupId>org.springframework.ai</groupId>
                <artifactId>spring-ai-openai-spring-boot-starter</artifactId>

    </dependencies>

    <build>
        <plugins>
            <plugin>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-maven-plugin</artifactId>
            </plugin>
        </plugins>
    </build>

```

#### 第四步：配置 application.yml

在 `src/main/resources/` 下创建或修改 `application.yml`：

```yaml

    name: spring-ai-demo
  ai:
    ollama:
      base-url: http://localhost:11434
```

**方案 B（DeepSeek）：**

```yaml

  application:
    name: spring-ai-demo
  ai:
    openai:
      base-url: https://api.deepseek.com/v1
      api-key: ${DEEPSEEK_API_KEY}
      chat:
        options:
          model: deepseek-chat
```

**方案 C（OpenAI）：**

```yaml

  application:
    name: spring-ai-demo
  ai:
    openai:
      api-key: ${OPENAI_API_KEY}
      chat:
        options:
          model: gpt-4o-mini
```

#### 第五步：编写 Hello World 代码

**1. 创建启动类**

`src/main/java/com/example/demo/SpringAiDemoApplication.java`：

```java
package com.example.demo;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class SpringAiDemoApplication {
    public static void main(String[] args) {
        SpringApplication.run(SpringAiDemoApplication.class, args);
    }
}
```

**2. 创建聊天控制器**

`src/main/java/com/example/demo/ChatController.java`：

```java
package com.example.demo;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class ChatController {

    private final ChatClient chatClient;

    // ChatClient.Builder 由 Spring AI 自动装配，注入即用
    public ChatController(ChatClient.Builder builder) {
        this.chatClient = builder.build();
    }

    // GET /chat?msg=你好
    @GetMapping("/chat")
    public String chat(@RequestParam String msg) {
        return chatClient.prompt()
                .user(msg)
                .call()
                .content();
    }
}
```

这段代码的核心就三件事：
- 通过构造函数注入 `ChatClient.Builder`（Spring AI 自动配置提供）
- 调用 `.build()` 创建 `ChatClient` 实例
- 用链式 API `.prompt().user(msg).call().content()` 完成一次 AI 调用

#### 第六步：启动并验证

**1. 启动项目**

```bash
mvn spring-boot:run
```

或者在 IDE 中直接运行 `SpringAiDemoApplication` 的 `main` 方法。

启动成功后，控制台会显示：
```
Tomcat started on port 8080
```

**2. 测试接口**

打开浏览器访问：
```
http://localhost:8080/chat?msg=用一句话介绍你自己
```

或者用 curl：
```bash
curl "http://localhost:8080/chat?msg=用一句话介绍你自己"
```

**预期结果**：几秒钟后返回模型的回复文本，例如：
```
我是一个AI助手，可以帮你回答问题、提供建议和完成各种任务。
```
