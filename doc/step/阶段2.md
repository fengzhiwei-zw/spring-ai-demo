### 阶段 2：ChatClient 深入

#### 一、ChatClient 的创建方式

ChatClient 有两种创建方式，理解它们的区别很重要：

**方式一：构造函数注入 Builder（推荐，简单场景）**

这是阶段 1 已经用过的方式，适合单模型、无默认配置的场景：

```java
@RestController
public class ChatController {

    private final ChatClient chatClient;

    public ChatController(ChatClient.Builder builder) {
        this.chatClient = builder.build();
    }
}
```

**方式二：通过 @Bean 预配置（推荐，生产场景）**

当需要设定默认系统消息、默认模型参数、默认 Advisor 时，用这种方式更优雅：

```java
@Configuration
public class ChatClientConfig {

    @Bean
    public ChatClient chatClient(ChatClient.Builder builder) {
        return builder
                .defaultSystem("你是一位资深Java架构师，回答要简洁专业，不超过200字")
                .defaultAdvisors(new SimpleLoggerAdvisor())
                .build();
    }
}
```

然后在 Controller 中直接注入 `ChatClient`：

```java
@RestController
public class ChatController {

    private final ChatClient chatClient;

    public ChatController(ChatClient chatClient) {
        this.chatClient = chatClient;
    }
}
```

> 后续所有示例都基于方式二，假设你已经通过 `@Bean` 创建了 `ChatClient`。

---

#### 二、同步调用 `.call()`

同步调用会阻塞线程直到模型返回完整结果，适合后端服务间调用、批处理等场景。

**基础调用**

```java
@GetMapping("/chat")
public String chat(@RequestParam String msg) {
    return chatClient.prompt()
            .user(msg)
            .call()           // 触发同步调用
            .content();       // 提取文本内容
}
```

**调用链路拆解**

```
chatClient.prompt()     → 创建 PromptSpec（请求构建器）
        .user(msg)      → 设置用户消息
        .call()         → 发送请求，返回 CallResponseSpec
        .content()      → 从响应中提取纯文本
```

**获取完整响应对象**

如果你需要更多信息（Token 用量、模型名称等），不要调用 `.content()`，而是调用 `.chatResponse()`：

```java
@GetMapping("/chat/detail")
public Map<String, Object> chatDetail(@RequestParam String msg) {
    ChatResponse response = chatClient.prompt()
            .user(msg)
            .call()
            .chatResponse();

    // 提取各种元信息
    Generation generation = response.getResult();
    String text = generation.getOutput().getText();
    
    ChatResponseMetadata metadata = response.getMetadata();
    Usage usage = metadata.getUsage();

    return Map.of(
        "content", text,
        "model", metadata.getModel(),
        "promptTokens", usage.getPromptTokens(),
        "completionTokens", usage.getCompletionTokens(),
        "totalTokens", usage.getTotalTokens()
    );
}
```

访问 `/chat/detail?msg=你好`，预期返回类似：

```json
{
  "content": "你好！有什么可以帮你的吗？",
  "model": "qwen2.5:7b",
  "promptTokens": 9,
  "completionTokens": 12,
  "totalTokens": 21
}
```

#### 三、流式调用 `.stream()` ⭐

流式调用返回 `Flux<T>`，模型每生成一小段文本就立即推送给客户端，实现"打字机"效果。这是用户交互场景的标配。

**基础流式调用**

```java
@GetMapping(value = "/chat/stream", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
public Flux<String> chatStream(@RequestParam String msg) {
    return chatClient.prompt()
            .user(msg)
            .stream()         // 触发流式调用
            .content();       // 返回 Flux<String>，每个元素是一小段文本
}
```

关键点：
- `produces = MediaType.TEXT_EVENT_STREAM_VALUE`：告诉 Spring 这是 SSE 接口
- `.stream()` 返回 `Flux<ChatResponse>`，`.content()` 将其转为 `Flux<String>`
- 每个 `String` 元素是模型增量输出的一小段文本（通常几个字到十几个字）

**测试流式接口**

浏览器直接访问 SSE 接口不太方便，推荐用 curl：

```bash
curl -N http://localhost:8080/chat/stream?msg=用200字介绍Spring框架
```

`-N` 参数禁用缓冲，你会看到文本一段一段地"流"出来：

```
data:Spring
data:框架
data:是
data:Java企业级应用开发
data:中最流行的
data:轻量级框架...
```

**获取完整流式响应**

与同步调用类似，如果需要元信息：

```java
@GetMapping(value = "/chat/stream/detail", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
public Flux<ChatResponse> chatStreamDetail(@RequestParam String msg) {
    return chatClient.prompt()
            .user(msg)
            .stream()
            .chatResponse();   // 返回 Flux<ChatResponse>
}
```

#### 四、系统消息设定

系统消息（System Message）是给模型的"人设指令"，决定了模型的角色、风格和行为边界。它有三种设定方式：

**方式一：@Bean 预配置默认系统消息（全局生效）**

```java
@Bean
public ChatClient chatClient(ChatClient.Builder builder) {
    return builder
            .defaultSystem("你是一位资深Java架构师，回答要简洁专业")
            .build();
}
```

所有通过该 ChatClient 发出的请求都会自动携带这条系统消息。

**方式二：请求级覆盖（单次请求生效）**

```java
chatClient.prompt()
        .system("你是一位幽默的段子手，用搞笑的方式回答问题")
        .user("什么是递归？")
        .call()
        .content();
```

请求级的 `.system()` 会**覆盖**（不是追加）默认系统消息。

**方式三：带变量的系统消息模板**

```java
chatClient.prompt()
        .system("你是一位{role}，回答风格要{style}",
                Map.of("role", "小学数学老师", "style", "通俗易懂"))
        .user("什么是分数？")
        .call()
        .content();
```

**实战示例：不同角色对比**

```java
@RestController
public class RoleController {

    private final ChatClient chatClient;

    public RoleController(ChatClient chatClient) {
        this.chatClient = chatClient;
    }

    @GetMapping("/explain")
    public String explain(
            @RequestParam String topic,
            @RequestParam(defaultValue = "专家") String role) {

        return chatClient.prompt()
                .system("你是一位{role}，请用适合{role}的语言解释概念",
                        Map.of("role", role))
                .user("请解释：{topic}", Map.of("topic", topic))
                .call()
                .content();
    }
}
```

访问：
- `/explain?topic=微服务&role=小学生` → 得到通俗的解释
- `/explain?topic=微服务&role=CTO` → 得到专业的解释

#### 五、用户消息的多种写法

用户消息不只有简单的字符串一种写法：

**基础写法**
```java
.user("你好")
```

**带变量的模板写法**
```java
.user("请用{language}解释{concept}",
      Map.of("language", "中文", "concept", "依赖注入"))
```

**函数式写法（适合复杂场景）**
```java
.user(u -> u.text("分析这张图片")
            .media(MimeTypeUtils.IMAGE_PNG, imageResource))
```

#### 六、模型参数调优

通过 `.options()` 可以调整模型的生成行为：

```java
chatClient.prompt()
        .user("写一首关于编程的诗")
        .options(ChatOptions.builder()
                .temperature(0.9)      // 创造性（0~2，越高越发散）
                .topP(0.95)            // 核采样
                .maxTokens(500)        // 最大输出Token数
                .build())
        .call()
        .content();
```

常用参数说明：

| 参数 | 范围 | 作用 |
|------|------|------|
| `temperature` | 0~2 | 越低越确定，越高越发散 |
| `topP` | 0~1 | 控制候选词范围 |
| `maxTokens` | 正整数 | 限制输出长度 |

> 也可以在 `application.yml` 中设置全局默认值：
> ```yaml
> spring:
>   ai:
>     ollama:
>       chat:
>         options:
>           temperature: 0.7
>           max-tokens: 1024
> ```

#### 七、异常处理

模型调用可能因为网络超时、模型服务不可用等原因失败，生产环境必须处理异常：

```java
@GetMapping("/chat/safe")
public String chatSafe(@RequestParam String msg) {
    try {
        return chatClient.prompt()
                .user(msg)
                .call()
                .content();
    } catch (org.springframework.ai.retry.NonTransientAiException e) {
        // 不可重试的异常（如API Key无效、配额用完）
        return "AI服务配置异常，请联系管理员";
    } catch (org.springframework.ai.retry.TransientAiException e) {
        // 可重试的异常（如网络超时）
        return "AI服务暂时不可用，请稍后重试";
    } catch (Exception e) {
        return "服务异常: " + e.getMessage();
    }
}
```

#### 八、完整实战代码

把以上知识整合到一个完整的 Controller 中：

```java
package com.example.demo;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.model.ChatResponse;
import org.springframework.ai.chat.metadata.ChatResponseMetadata;
import org.springframework.ai.chat.metadata.Usage;
import org.springframework.ai.chat.model.Generation;
import org.springframework.http.MediaType;
import org.springframework.web.bind.annotation.*;
import reactor.core.publisher.Flux;

import java.util.Map;

@RestController
@RequestMapping("/api")
public class ChatController {

    private final ChatClient chatClient;

    public ChatController(ChatClient chatClient) {
        this.chatClient = chatClient;
    }

    /**
     * 1. 基础同步调用
     */
    @GetMapping("/chat")
    public String chat(@RequestParam String msg) {
        return chatClient.prompt()
                .user(msg)
                .call()
                .content();
    }

    /**
     * 2. 同步调用 - 返回详细信息
     */
    @GetMapping("/chat/detail")
    public Map<String, Object> chatDetail(@RequestParam String msg) {
        ChatResponse response = chatClient.prompt()
                .user(msg)
                .call()
                .chatResponse();

        Generation gen = response.getResult();
        ChatResponseMetadata meta = response.getMetadata();
        Usage usage = meta.getUsage();

        return Map.of(
            "content", gen.getOutput().getText(),
            "model", meta.getModel(),
            "promptTokens", usage.getPromptTokens(),
            "completionTokens", usage.getCompletionTokens(),
            "totalTokens", usage.getTotalTokens()
        );
    }

    /**
     * 3. 流式调用 - SSE 打字机效果
     * curl -N --get \
     --data-urlencode "msg=用一句话介绍你自己" \
     http://localhost:8080/chat/stream
     */
    @GetMapping(value = "/chat/stream", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
    public Flux<String> chatStream(@RequestParam String msg) {
        return chatClient.prompt()
                .user(msg)
                .stream()
                .content();
    }

    /**
     * 4. 带角色设定的调用
     */
    @GetMapping("/chat/role")
    public String chatWithRole(
            @RequestParam String msg,
            @RequestParam(defaultValue = "资深Java架构师") String role) {
        return chatClient.prompt()
                .system("你是一位{role}，回答要专业且简洁",
                        Map.of("role", role))
                .user(msg)
                .call()
                .content();
    }

    /**
     * 5. 带参数调优的调用
     */
    @GetMapping("/chat/creative")
    public String chatCreative(@RequestParam String msg) {
        return chatClient.prompt()
                .user(msg)
                .options(org.springframework.ai.chat.prompt.ChatOptions.builder()
                        .temperature(0.9)
                        .maxTokens(800)
                        .build())
                .call()
                .content();
    }
}
```
